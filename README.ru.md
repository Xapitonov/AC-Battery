# Виджет AC-Battery

![Иконка](art/launcher_icon-web.png)

AC-Battery — это виджет для Android, предназначенный для отображения уровня заряда батареи.

## Снимок экрана

![скриншот-00](art/screenshot-00.png)

## Инструкция по сборке

Чтобы собрать AC-Battery, выполните следующие шаги:

```bash
$ git clone https://github.com/seven332/AC-Battery
$ cd AC-Battery
$ gradlew app:assembleDebug
```

Сгенерированный APK файл можно найти в каталоге `app/build/outputs/apk`.

## Благодарность

Данный проект основан на [Android-Battery-Widget](https://github.com/er-mo/Android-Battery-Widget) от er-mo.
